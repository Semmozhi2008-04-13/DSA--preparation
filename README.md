# 🔥 My Grind Rules

> **Understand → Implement → Practice → Repeat**

* Don't just memorize solutions.
* Understand **why** the pattern works.
* Try implementation before looking at the solution.
* Learn from every mistake.
* Revisit problems I couldn't solve.
* Focus on patterns, not random questions.
* Keep moving forward.
